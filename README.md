# AER Link Witness

AER Link Witness is being built to observe address-event links and routers under complete prior traffic schedules, locating loss, duplicate delivery, reorder, service delay and lack of progress. This checkout contains repository validation tooling and documentation. Full foundation qualification is in progress. There is no installed link-analysis package, traffic generator, public link-analysis command or qualified link report.

## Boundary

This project owns the intended instrument generator and monitor, traffic schedules, independent sequence and pending-work analysis, and report. SC-NeuroCore owns the implementations under test. Loop Timing Witness supplies the actual capture, timebase, instrument acceptance and target adapters. Evidence Manifest Toolkit supplies shared evidence operations.

Original spike opportunities, accepted packets, expected fanout deliveries and legitimate receipts are different populations. Software models, instrument simulation and measured fabric are different evidence scopes. A finite sweep cannot establish universal capacity, starvation freedom or a probabilistic zero-loss guarantee.

## Current tooling

Seven repository controls inspect metadata, source attribution, workflows, dependency alignment, native documentation, inventory and preflight orchestration. Native-tool bootstrap checks selected development executable and licence bytes. Domain capabilities, claims and qualified formats remain empty at architecture-only maturity.

Use the exact environment in [Contributing](CONTRIBUTING.md). Named commands are make metadata, make source-provenance, make workflows, make dependencies, make docs, make inventory and make licence. Full CI/preflight belongs in CI or an explicitly admitted pre-push environment. See [Validation](VALIDATION.md) for the scope.

## Intended evidence

A report will retain the actual source, routing and adapter configuration, all prior pattern/load/repeat/flow cells, exact event and payload identities, complete capture and drain coverage, clock interpretation and located outcomes. Missing observations and unqualified instrument inputs remain visible. The planned report format is neither registered nor qualified here.
