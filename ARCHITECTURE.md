# Architecture

## Current executable surface

Repository validation tooling, dedicated tests, workflow definitions and native documentation are implemented. No traffic generator, monitor, source adapter, capture runner, sequence analyser or link-report command is installed. Domain capability, claim and qualified-format inventories remain empty.

## Intended data flow

A complete prior source, adapter, configuration and traffic plan defines all schedules and expected deliveries. Actual admitted instrumentation captures raw observations, coverage and pending work. Independent analysis accounts for every expected delivery and watchdog window. A full report uses installed shared evidence operations. Separate consumers verify exact source, scope and references; Studio renders the existing findings.

## Ownership

AER Link Witness owns generator and monitor IP, schedules, independent analysis and reports. SC-NeuroCore retains the DUT implementations. Loop Timing Witness owns timebase, capture and instrument acceptance; Evidence Manifest Toolkit owns shared evidence operations. Studio renders existing results. Deployment, benchmark, reliability and safety consumers retain the exact tested scope.

## Interpretation

Keep spike opportunities, accepted packets, fanout deliveries and receipts distinct. Unknown payload, identity, time or coverage never becomes a valid receipt. Received-only delay is separate from the complete service bound. Instrument simulation does not establish measured fabric performance. Read [the documentation architecture](docs/ARCHITECTURE.md) for full boundaries.
