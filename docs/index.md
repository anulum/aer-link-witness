# AER Link Witness

This repository is preparing an address-event link observation instrument. Its current executable surface is repository validation tooling. It has no installed link-analysis package, public traffic runner or qualified link report.

AER Link Witness is part of the **SC Neuromorphic Computing Systems** group (SC-NEUROMORPHIC-COMPUTING-SYSTEMS). The [group and project map](https://github.com/anulum/sc-neurocore/blob/main/docs/ecosystem.md) shows the whole programme and where this repository sits in it.

The intended workflow retains complete prior traffic populations, actual source and adapter behavior, original raw observations and coverage. Independent sequence and pending-work analysis preserves every missing or contradictory observation. Instrument simulation and actual measured fabric remain separate.

Read [Architecture](ARCHITECTURE.md), [validation tooling](validation-tooling.md), [data boundaries](THREAT_MODEL.md) and the [repository boundary decision](adr/0001-repository-boundary.md).
