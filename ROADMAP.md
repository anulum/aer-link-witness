# Roadmap

## Current foundation

Repository identity, legal texts, architecture, governance, native documentation and dedicated validation tools are being qualified. Domain capabilities and claims remain empty.

## Capability milestones

Bind actual source-owned encoder, router, priority queue and delay-tap behavior to complete independently interpreted adapters. Implement all six prior traffic schedules and full expected flow/load/repeat populations. Independently qualify the real generator, monitor, raw format and capture chain in simulation.

Complete sequence accounting, censored service-delay and pending-work watchdog analysis must retain every failed or unavailable cell. Actual admitted capture then supports complete reports through installed shared evidence operations, independent consumers and Studio rendering. Physical claims require actual board, timebase, coverage and uncertainty evidence.

Each implemented surface includes strict native quality, documentation, meaningful coverage, actual counterpart parity and affected benchmarks. Public activation, release and external reproduction require their own evidence. No availability date or performance advantage is promised.
